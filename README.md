# HOOPLOG v13 · 基于个人日常基准的直线趋势箭头

基于 v12 正式代码更新，保留原有 Google Drive 读取、Excel A-E 列匹配、视频片段筛选、IndexedDB 离线缓存与播放。

## 新增 / 更新
- 数据统计默认进入「对比」；顶部标题、单次/汇总/对比、自动推荐选择区域统一折叠在一条“训练对比”栏中，点击展开。
- 自动选场继续使用 v12 规则：最新训练所属星期的最近一次与之前最多 3 次训练；可跨星期手动勾选，支持恢复自动推荐。
- 总得分、原地投篮（出手/命中/命中率）、一次突破上篮（出手/命中/命中率）的字号增加；每相邻两场之间直接画红/绿/灰直线箭头和差值。
- 每个箭头角度按对应指标的日常基准与平滑饱和曲线自动计算：
  angle=34° * (1 - exp(-abs(本场-上场)/scale))
  scale=基准*相对系数+最小噪声，避免小基数的 1~2 次波动造成大角度。
- 采用用户给出的基准：总分 20、原地出手 20、命中率 30%、一次突破出手 5、命中率 50%。命中次数基准分别由此推得 6 与约 2.5 次。
- 最大角度 34°。纯直线+空心箭头尖。统计数字差异只表达该指标的数值升降，不直接判定技术进步或退步。
- 无有效出手时不计算命中率，显示 —，防止 NaN。

## 发布步骤
1. 在 GitHub Pages 对应仓库的根目录，用本包中的 index.html、sw.js、manifest.webmanifest 替换原文件并提交。
2. GitHub Releases 创建 tag v13，可附加 HOOPLOG_v13.zip。
3. 重新打开 iPhone Safari/桌面图标，确认代码更新。不要清除 Safari 网站数据或 IndexedDB；本次未改变存储数据库名称和结构。
