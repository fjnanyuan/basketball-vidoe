# HOOPLOG v9 更新说明

1. 「篮球」总文件夹链接、同步 Excel、清理旧文件夹记录，全部移到「设置」页面。
2. 「文件夹」页面只显示子文件夹、缓存与删除缓存。
3. 数据统计中「突破上篮」更名为「一次突破上篮」，统计按 Excel C 列完全匹配。
4. 「视频片段」新增投篮类、突破类、篮下终结类、传球类、防守/篮板类、失误/其他、其他动作、未分类筛选。
5. 一个视频允许多条 Excel 动作记录，可同时出现在多个分类中；视频列表与播放器显示所有动作。
6. 保留 Wi-Fi 两次确认、Excel A-E 列映射、下载诊断及现有缓存逻辑。

在 GitHub 仓库根目录替换 index.html 和 sw.js，提交并等待 Pages 发布。打开网站的「设置」即可同步「篮球」总文件夹。

注意：本版未解决先前 iPhone Safari 的 IndexedDB 视频写入失败；此问题仍需在普通（非私密）Safari 页面验证。
