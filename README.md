# HOOPLOG v15 · 每日训练计划 / 右突 60% / 6–9 秒

基于 HOOPLOG v14 完整网站升级，保留文件夹、数据统计（含 v13 对比）、Google Drive Excel 同步、视频片段、本机 IndexedDB 缓存与现有训练动态画面。

## 本次变化

1. **每天训练一次**：训练中心显示每日目标 `1 次`、当天已完成次数和上一次训练摘要。一天训练多次也正常记录，不会限制训练。
2. **每次训练单独保存**：在开始后至少触发一次方向提示，停止训练、切走其他页或网页进入后台时，保存开始日期时间、模式、间隔、回合数、提示向左/向右次数和训练时长。最近 7 次在「训练中心」查看。没有发出任何提示的训练不计入当日完成次数。
3. **向右突破概率 60%**：每次提示独立随机，右 60%、左 40%。这指系统出题目标方向，短时间内不保证恰好 6:4；允许连续出现相同方向。防守前脚和协防站位随目标方向联动，使正确方向与实际画面一致。
4. **时间选项 6 / 7 / 8 / 9 秒**：默认 7 秒。保留自动连续训练、三种模式、隐藏方向箭头、大画面。

## 训练记录保存在哪里

训练历史存于**当前浏览器的 localStorage**，键名 `hooplog_training_sessions_v15`。不上传到 GitHub 或 Google Drive，也不会自动在设备之间同步。清除 Safari 网站数据、切换不同来源的网页或隐私浏览可能导致记录丢失。训练记录目前保留最近 365 次，每次保存后可在训练目录查看最近 7 次。

数据中「方向次数」代表软件发出的提示次数，不代表摄像头识别或证明你实际完成动作的次数。

## 部署 GitHub Pages

解压 ZIP，将 `index.html`、`sw.js`、`manifest.webmanifest` 覆盖到 `basketball-vidoe` 仓库的网站根目录并提交。发布后刷新 Safari；已添加至主屏幕的网页若仍旧显示旧页面，可先完全关闭再重新打开。

升级只更新网页及网页壳缓存版本号，不改现有 IndexedDB 数据库名称/结构，也不主动删除本机离线视频。不要手动清除 Safari 网站数据来强制升级，否则可能丢失视频与训练记录。

## 测试范围

已验证 HTML/JavaScript 语法，并用 Chromium 在 390px 手机宽度测试：打开训练、选项、开始出题、停止保存、返回目录查看、再开始并切换标签保存、放大画面等。真实 iPhone Safari 与 Google Drive OAuth 需部署后在目标设备确认。
