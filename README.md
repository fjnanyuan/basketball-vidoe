# HOOPLOG v17 · 统计对比五项动作齐全

本版基于 HOOPLOG v16 完整源代码，针对 **数据统计 → 对比** 页面补齐此前遗漏的「篮下直接终结」「一次突破急停跳投」两张卡片，并将五项投篮动作的顺序保持统一。

## 五项显示顺序
1. 原地投篮
2. 一次突破上篮
3. 篮下反篮
4. 篮下直接终结
5. 一次突破急停跳投

每个动作在对比页面均包含：出手、命中、命中率；逐场直线箭头及变化量，箭头倾斜度沿用基于个人常见规模的饱和曲线。原有总得分、默认折叠顶部、同星期最近最多四场自动推荐、手动选择场次全部保留。

原有 v16 已支持上述五项的 Excel 统计及单次/汇总，所以不需要增加或修改 Excel 列。仅对 v16 未设定个人基准的「篮下直接终结」及「一次突破急停跳投」使用保守的临时小样本趋势尺度；不会假定它们的表现等同于你其他动作的长期水平。

## 保留的功能
- Google Drive OAuth 读取、Excel 同步、视频片段筛选、IndexedDB 视频离线缓存。
- v15 每日训练计划、本机训练记录、向右突破概率 60%、6 / 7 / 8 / 9 秒选择。
- 同一天不同文件夹独立统计。自动对比最多取最近四场同星期训练，而非按天合并。
- 所有历史数据本地保存键未更改，本版不迁移或清理数据。

## 安装
将 ZIP 内 `index.html`、`sw.js`、`manifest.webmanifest` 上传覆盖 GitHub Pages 仓库同名文件并提交。`sw.js` 的离线网页壳缓存名称升级为 `hooplog-shell-v17`，不会删除 IndexedDB 中的视频和训练记录。若页面仍显示旧版，先尝试关闭并重新打开 HOOPLOG，而非删除 Safari 网站数据。

## 测试说明
对网页脚本和 Service Worker 进行了语法检测；通过构造的训练数据验证五项动作的顺序、统计值及箭头。未使用真实 Google 授权或在用户手机实际执行。

## 动作名称修正（v17 修正版）
「一次突破急停跳投」为唯一显示名称。Excel C 列可填写「一次突破急停跳投」；为兼容此前 v17 发布包，也识别旧写法「突破急停跳投」，并将其归入同一统计项，不重复计算。已安装 v17 的用户直接覆盖三个文件即可，视频及训练记录保留。
