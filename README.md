# HOOPLOG v12 · 自动按星期对比（正式发布）

## 本次修改

1. 进入「数据统计」时，默认打开「对比」模式，而不是「单次」模式。主页面仍然是「文件夹」。
2. **自动选最近一次实际训练，及同星期的之前最多 3 场**，合计最多 4 场。例如最新记录是周三，就默认对比近 4 次周三；最新记录是周六，就默认对比近 4 次周六。不是固定写死周三/周六；周日也适用。
3. 自动依据文件夹**名称开头的日期**（例如 `1028周三b面`、`20261028训练`、`2026-10-28训练`）判定实际星期；跨年尽量按最近过去日期理解。无法解析日期时回退到最近更新的 4 场。未到日期的明确年份文件夹不会作为默认最新训练。
4. 「自动推荐对比」默认收起长文件夹列表，打开页面即可看到总得分速览、原地投篮、一次突破上篮和完整逐场变化。点击「调整场次」展开，支持任意勾选、全选、最近两场及恢复自动推荐。**手动修改后不会立刻被自动选择覆盖**，当前页面会话里保持手动选择；刷新网页后恢复自动默认。
5. 保留 v11 所有已确认的统计显示方式，包含总得分变化与两类动作的命中率、出手、命中变化。
6. 保留视频片段函数、Google Drive 同步和 IndexedDB 离线视频缓存，未修改数据库名称及存储结构。

## GitHub Pages 发布步骤

- 备份仓库根目录的 `index.html`、`sw.js`、`manifest.webmanifest`。
- 上传这三个文件到根目录并提交；无需替换 Google Drive 中的视频或 Excel。
- 在 GitHub Releases 里可创建 `v12` 标签，将 ZIP 附上。
- 部署后重新打开网页查看新界面；**不要清除 Safari 网站数据**，否则可能丢失已缓存的视频。

## 注意

比较的日期依靠文件夹名称开头的月日；与其星期是否真的对应，取决于手机所在年份对日期的推断。若存在多个年份但文件夹名没有年份，建议在名称中添加年份以消除歧义。
