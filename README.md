HOOPLOG v10.1 · 方案一（全部指标展开）

基于现有 v10（多场统计对比，带“具体动作对比”下拉选择）修改。

更新内容：
- “对比”页面的命中率、得分、出手、命中四组条形图同时显示，不再需要切换按钮。
- 支持勾选 1/2/3 场或更多，所有组同时响应所选训练。
- 各场颜色在本次数据展示中保持一致；保留“逐场变化”和“具体动作对比”。
- 得分仍按每次命中 2 分计算；命中率按有效出手计算。
- 不修改 Google 登录、Drive 同步、Excel 解析、IndexedDB 缓存及视频播放逻辑。
- Service Worker 外壳缓存版本提升到 v10-1，避免旧 HTML 持续显示。

部署：
将 index.html 和 sw.js 上传替换到 GitHub 仓库根目录；manifest.webmanifest 未变动，可不替换。
修改网站代码不会主动删除 Safari 里已缓存的篮球视频，但请勿在 iPhone 上清除该网站数据。
注意：本压缩包代码没有实际连接你的 Google Drive 做端到端测试；请部署后核对数据。
