# HOOPLOG v14 · 读防守启动反应训练

这是基于用户现有 **HOOPLOG v13** 的完整升级包，保留 GitHub Pages 网站的 Google Drive 同步、Excel 解析、统计对比、离线视频和 IndexedDB 缓存逻辑，新增第 3 个底部导航 **「训练」**。

## 新增内容

- 训练中心 > **读防守 · 启动反应**。
- 手机架在支架上，一键开始、无需每回合触摸手机，防守人的脚步和协防情景自动变化。
- 模式① 直接左右反应，② 前脚判断，③ 前脚 + 内线协防。
- 情景切换间隔：7 秒、5 秒、3.5 秒；每次含约 0.85 秒回到中立站姿。
- 进阶挑战：初始不显示正确方向，临近下一回合才显示参考答案。
- 大画面模式、开始/停止、自动回合及左右提示次数。
- 离开训练页、切换浏览器到后台时会停止计时，不会假装你还在训练。
- 当前为视觉刺激训练，不读取摄像头，也不检测动作是否真的完成。统计是提示次数，不是成功动作次数。

## 升级到 GitHub Pages

1. 下载并解压 `HOOPLOG_v14.zip`。
2. 将其中 `index.html`、`sw.js`、`manifest.webmanifest` 三个文件上传到 GitHub 仓库 `basketball-vidoe` 的网站根目录，替换同名文件。
3. 提交后访问 GitHub Pages 网址并刷新。Safari 已添加到主屏幕时如未更新，关闭网页再打开，必要时重启添加的网页应用。
4. 打开底部「训练」→「读防守 · 启动反应」→ 选择模式及速度 → 点击「开始连续训练」。

## 原有数据保留

升级只改网页代码和 Service Worker 的**网页外壳缓存版本号**，不修改 IndexedDB 的数据库名称、版本号或表结构，不主动清除缓存视频。切勿为了升级而手动删除 Safari 网站数据，否则可能丢失本机视频缓存。

## 训练提示

先练「② 读防守前脚」5 秒模式，看到防守人前脚变化后向对应侧做第一步启动。熟悉后隐藏方向提示，最后加入协防。攻击前脚只是训练启发式，实际比赛仍要判断距离、重心、髋部方向与内线空间。建议把手机支架远离突破路线，确保周围留有足够空间。

## 文件

- `index.html`：完整静态单页应用和训练交互逻辑。
- `sw.js`：站点网页外壳缓存；不缓存 Google Drive 内容。
- `manifest.webmanifest`：保留现有主屏幕安装配置。

构建源文件：HOOPLOG v13；升级编号：v14。
