# HOOPLOG v16 · 新增「篮下反篮」投篮动作

本包以 **HOOPLOG v15 完整网站**为基础，仅扩展投篮动作统计与筛选，并将网页缓存版本升级为 v16。包含 `index.html`、`sw.js`、`manifest.webmanifest` 三个部署文件（附 README）。

## 新增内容

- **Excel 读取**：C 列动作准确填写 `篮下反篮`，D 列填写 `成功` / `失败`。原格式（A 文件夹名、B 视频文件名、C 动作、D 结果、E 备注）不变，不需要新加 Excel 列。
- **单次统计**：「动作分析」新增「篮下反篮」出手、命中、命中率，包含在现有得分和投篮汇总里（每次成功按 2 分估算）。
- **多场汇总**：「动作汇总」新增独立的「篮下反篮」，统计所有勾选场次的命中、出手、命中率。
- **训练对比**：原有「原地投篮」「一次突破上篮」不变，在下方新增「篮下反篮」三项逐场数据（出手、命中、命中率）以及按 v13 的个人基准算法显示的红/绿直线箭头。由于「篮下反篮」尚无你的长期基准，暂采用一次突破上篮的小样本尺度，后续有足够数据再调整。
- **视频片段**：原来的「篮下终结类」依然包含反篮视频，同时新增一个精确筛选「篮下反篮」。视频详情保留原动作名称与 Excel 备注。一个视频有多条动作记录时仍可属于多个分类。

## 特别注意

1. 只更新网页代码**不会自动修改已有 Google Drive Excel**。请自行在 Excel 的 C 列新增 `篮下反篮` 行，刷新网站并通过「设置 → 同步子文件夹与 Excel」读取后生效。没有匹配记录的旧场次显示 0 次，不会凭空生成出手。
2. 动作独立分类：`篮下反篮` 不会重复计入 `篮下直接终结`。总得分沿用此前规则，每次命中按两分估算。
3. v15 的「每日训练计划」「右侧 60%」「6/7/8/9 秒」、本机训练历史与 IndexedDB 视频缓存结构均未更改。训练历史继续使用 `hooplog_training_sessions_v15` 本地保存键，不迁移、不删除。
4. 自动选最近同星期最多 4 场和手动调整的旧规则保持不变；同一天两个场地仍视为两场独立记录。
5. 不会把本地视频或训练记录自动上传到 GitHub 或 Google Drive。

## 发布

解压 ZIP，把 `index.html`、`sw.js`、`manifest.webmanifest` 覆盖到 `basketball-vidoe` 仓库的网站根目录并提交。GitHub Pages 发布后用 Safari 打开原网址，必要时关闭后重新打开网页，服务工作线程会以 `hooplog-shell-v16` 更新网页壳缓存。

**不要清除 Safari 网站数据**来刷新版本：那可能删除本地训练历史和离线视频。

## 测试

对 HTML 内联 JavaScript 与 Service Worker 执行语法检查；使用隔离测试数据验证新动作单次、汇总、对比、视频筛选、分类与得分计算。真实 Google Drive OAuth 与 iPhone Safari 需要在目标设备上验证。
